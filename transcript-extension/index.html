Features

What makes it different

Most transcription tools join as a bot or require you to record the screen. This captures audio directly from the tab — no extra participants, no awkward notices.

🎙️

Acoustic speaker diarization

Deepgram Nova-2 identifies distinct speakers by voiceprint — not just turn-taking. Each speaker gets consistent labeling throughout the session.

⚡

Real-time streaming

WebSocket connection to Deepgram — transcription appears as it's spoken, not after the call ends. No waiting, no post-processing lag.

⏸️

Pause and resume

Freeze transcription mid-call without losing the session. Resume seamlessly — speaker context and transcript continuity are preserved.

📁

Three output formats

Every session saves as .txt (plain), .md (structured with speaker labels and timestamps), and .json (machine-readable, full metadata). Organized in per-session subfolders.

🐙

GitHub auto-commit

Transcripts commit to your configured GitHub repo automatically when the session ends. Supports GitHub Enterprise for corporate setups.

🔒

VPN and corporate network ready

Designed for enterprise environments. Tested on VPN-locked networks where other transcription tools fail to connect.

Sneak Peek

Inside the extension

A look at what's under the hood — full source and setup instructions are in the repo.

Module Content Script

Intercepts the tab's audio stream at the browser level — no screen capture, no bots, no additional meeting participants.

Module Deepgram Bridge

Manages the WebSocket lifecycle — connection, auth, streaming chunks, reconnect on drop — with Deepgram Nova-2's diarization endpoint.

Module Speaker Tracker

Maps acoustic speaker IDs to consistent labels across the session. Labels persist through speaker gaps and reconnects.

Module File Writer

Writes all three formats on session end — .txt, .md with structured headers and timestamps, .json with full diarization metadata.

Module GitHub Sync

Commits the session folder to your configured repo using the GitHub Contents API — supports PAT auth and GitHub Enterprise endpoints.

Module Popup UI

Clean controls for start, pause, resume, and stop — with live status display showing current speaker, confidence, and recording duration.
